# 商业街多人 NPC 互动与人物素材方案

商业街已经有双人移动、靠近互动、行为树和对话选项。下一步适合先做「玩家加两位 NPC」的小型对话组，再扩展成更多居民的街区活动。人物画风以本次提供的像素人物参考为准；当前两张四视角样张用于确定比例、线条和配色，还不是可直接替换的行走帧。

## 现有实现与限制

- [角色定义](../../client/src/features/city/scene/commercialStreetCore.js)目前固定两套 64×80、四方向、每方向四张行走图，商业街与小屋共用。角色在世界中的显示大小由现有玩家缩放值控制。
- [街景入口](../../client/src/features/city/scene/CommercialStreetScene.jsx)把目标角色和玩家角色作为一对处理，靠两者距离决定互动菜单是否可用。现有距离阈值是 170 个世界单位。
- [互动执行](../../client/src/features/city/scene/behavior/useStreetBehaviorRuntime.js)当前只有一个活动行为运行器，`approach_player`、`face_player`、`offer_choices` 等步骤面向一个目标。请求载荷中的 `world.actors` 也只有 `role` 与 `user`。
- 商业街的图层、物件和碰撞已经稳定。新增 NPC 应沿用现有路径查询与脚底碰撞数据；人物立绘透明区域不应改变碰撞盒。

## 第一阶段的玩家体验

1. 玩家走近或点击一位 NPC，出现该 NPC 的「交谈」「邀请加入」「离开」菜单。未在互动距离内时，沿现有可行走路径靠近；路径失败时给出短提示。
2. 玩家与一位 NPC 对话时，可邀请附近另一位空闲 NPC。初版一个对话组最多三人：玩家和两位 NPC。受邀者有可达的站位才加入，保留人物间距，不传送或穿过物件。
3. 对话区显示当前发言者的头像或小人名牌，并一次只出现一条主要对白。旁观者可以显示简短表情，不抢发言。玩家可选回复，也可随时退出。
4. 玩家走远、切换场景、受邀 NPC 路径失败或会话超时，结束对话并释放站位。NPC 恢复原来的自主行为；单人互动继续沿用现有入口。

## 运行数据与调度建议

把「场景人物」和「对话组」分开管理。场景人物记录 `actorId`、绑定的实际角色 `characterId`、`spriteId`、位置、活动状态；对话组记录 `sessionId`、参与者 ID、有序发言记录、当前发言者、站位和状态。选中的 NPC 用 `focusActorId` 表示，不能再用「另一个固定角色」推断玩家。

会话状态按 `inviting → gathering → talking → closing` 流转。一个 NPC 同时只能属于一个会话或一个移动任务。前台先只运行一个对话组；远处 NPC 的日常招呼可用短预设台词，不需要为每个路过者发模型请求。场景帧循环只更新移动和显示，不在逐帧循环中请求 AI。

模型请求以**一个发言回合**为单位，传参与者的稳定 ID、姓名、关系摘要、当前位置语义、最近几轮对白、玩家选择和允许动作。返回 `speaker_id`、对白、可选表情、下一步意图；服务端验证发言者确实在组内、对白长度和动作白名单，不接受模型生成的像素坐标。失败时退回本地简短回应，不让整组卡住。

实现顺序建议为：先把双人目标改为显式 `focusActorId` 并保持原体验；再加第二位 NPC 的可视化和路径站位；最后加组内轮流发言与请求协议。每一步均可独立测试。现有行为树可继续存每个实际角色的个人行为，组内发言由会话协调器串行调度，不把整场多人对话塞进一个人的 `player_interaction` 分支。

## 人物画风与制作规格

参考图的关键特征是约三至四头身、细致但清晰的像素轮廓、暖色面部与头发高光，以及有层次的浅色服装。衣服以奶油白、浅卡其、浅鼠尾草绿、淡粉和浅蓝等低饱和浅色为主；深色只用于少量轮廓和阴影，避免深色外套、围裙、裙子或裤袜占据大面积。男女人物应使用一致的头身比例、线条粗细和像素细节密度；男装参考用户图片左上角的浅米色风衣、白色针织毛衣和浅色长裤，裤腿保持自然的直筒或微收窄轮廓，双手在风衣外自然下垂，左右侧面要画出正确的肩、肘和手腕连接。女性样张使用无发饰、不扎起的披散长发和浅蓝裙。发型要能在正面、两侧和背面对应起来，不能只在单一视角成立。新 NPC 要有各自的发型和衣服轮廓，避免只换颜色就变成另一位人物。

这两张是高分辨率透明 PNG 设定图。侧面朝向需要在制作最终帧时按游戏文件名核对；不能直接把整张图切入现有动画。实际运行素材仍按现有的 `front/back/left/right_walk_{idle,step_a,passing,step_b}.png` 输出，每人 16 张透明 PNG，所有方向脚底落点一致。先完成四方向静止帧，游戏中用原渲染尺寸检查头身比例和清晰度，再做走路循环；表情可先用独立气泡或头顶小图标，减少每套服装所需的全身帧数。

最终上场前检查透明边缘、连续帧脚底是否漂移、左右朝向、人物遮挡、商业街和小屋两个场景的缩放效果。若需要更高源分辨率，应保持世界中的显示尺寸与脚底锚点不变，不能顺带改动碰撞宽高或图层排序。

# 大输入库公共表达规则与提示审查

## 本轮目标

允许角色自然想起和提及相关往事，减少通过引号逐句回放用户、角色自己的旧对白。该边界应覆盖私聊、群聊、商业街日志、日记等自然语言生成入口，并清理替模型预先判定用户意图、回复话题、态度和答题顺序的规则。

## 共用入口

规则集中在 `server/utils/sharedContextGuidance.js` 的 `SHARED_CONTEXT_GUIDANCE`。

`buildUniversalContext` 的默认 `preamble` 包含这一公共规则，现有群聊、日记、记忆整理等调用方继续继承。另返回 `systemGuidance` 与不含重复规则的 `contextPreamble`：私聊主回复、普通/私聊触发商业街活动、商业街社交遭遇使用这两个字段，把规则明确放入 system 消息，数据放入各自上下文，避免重复注入。

公共规则只约束自然语言表达；JSON、字段、功能标签和动作协议保持原有要求。摘录和记忆整理任务保留其所需原文，防止正文去复述规则误伤记忆保存。

## 本次清理

| --- | --- |
| 加载商业街详情就断言用户在问生活轨迹，要求优先汇报去过哪、吃过什么等 | 删除该条件式答题清单，资料加载只表示内容可供参考 |

| 过去的睡觉、疲惫等信息都视为此刻真实处境 | 明确当前状态与带时间的过去记录分别理解 |
| 没有亲历记录就只能说没出门、没新经历或记不清 | 改为本次资料未覆盖，不据此断言没发生 |
| 用户说 AI、prompt 等词就预设对方在乱讲话、试探角色 | 删除这条动机预设 |
| 未回复次数决定下次必须带刺、黏人，收到回复也不能恢复平静 | 保留联系次数与是否收到回复，不规定下一句态度 |
| 时段直接决定说话长短、困倦和亲密节奏 | 保留日期时刻，说明时段本身不决定状态或语气 |
| 工作、休息、吃饭场景自动补写台词节奏和特定环境细节 | 保留当前活动、地点和已有状态数值 |
| 好感区间强制指定冷眼旁观、调情等反应，历史印象必须影响当前行为 | 改为关系记录和过去主观看法的参考边界 |
| 备用记忆提示称“真实旧信息”，只有冲突时才允许不确定 | 改为过去对话概况，保留不确定性；未启用额外召回路径 |
| 私聊最近 5 轮提过某事就一律不得再提 | 允许相关往事、有新进展或用户继续谈及的内容自然延续，避免重新铺陈来龙去脉 |

普通商业街活动原来的“如需引用话语，优先使用中文引号”格式偏好也移除，统一采用公共引用边界；本次新发生的对话仍可正常书写。

# 商业街 CSS 与接口说明

这个文件夹用于记录商业街相关前端样式入口、主要选择器职责，以及后端 `/api/city/*` 接口用途。

## 文件

- `commercial-street-css-and-api.md`：完整说明文档。

## 快速定位

- 商业街地图本体入口：`client/src/plugins/pixelWorld/CommercialStreetPanel.jsx`
- 商业街地图主 CSS：`client/src/plugins/pixelWorld/PixelWorldPanel.css`
- 商业街窗口/窄屏覆盖：`client/src/styles/desktop.css`
- 商业街日志入口：`client/src/plugins/city/CityLog.jsx`
- 商业街日志 CSS：`client/src/plugins/city/CityLog.css`
- 商业街管理后台：`client/src/plugins/city/CityManager.jsx`
- 后端核心接口：`server/plugins/city/routes/coreRoutes.js`
- 后端事件/任务接口：`server/plugins/city/routes/eventQuestRoutes.js`
- 后端行为模型/市长接口：`server/plugins/city/index.js`

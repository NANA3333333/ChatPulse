# 私聊重 roll

代码已迁入 private-chat 功能目录；入口清单与操作编号排错见 [私聊功能说明](features/private-chat.md)。

新生成的私聊回复会在最后一个气泡下显示 `‹ 1 / 1 ›`。

- 在最新版本按右箭头：复用本轮整理好的完整上下文，重新调用当前配置的主模型。
- 左右箭头：切换本轮已保存的版本；版本切换不调用模型。回到最新版本后再按右箭头可继续生成。
- 刷新页面或重启服务后，版本与选中的正文仍会保留。后续对话使用选中的正文。
- 一轮有多个气泡时，重 roll 会替换整轮文字。失败保留当前回复；生成期间删除或修改对话会取消过时的替换。

重 roll 不重新执行切题、摘要、模块路由、检索、联网规划等辅助步骤，也不重复执行转账、日记、城市动作或语音生成。原回复已经产生的这些行为不会撤销；重 roll 只改回复文字。联网回复保存并复用最终主回复收到的联网结果。

重 roll 会补充当前版本的私聊文风与防重复提示，因此已经保存上下文的旧回复也能使用新规则；保存的辅助结果和原始请求快照保持不变。

此功能适用于升级后新生成的私聊回复。旧消息没有保存完整生成上下文，无法补回当时的辅助结果。主动消息暂不提供重 roll。主模型如果返回截断内容，仍可能触发主模型续写。

## 验证

Windows 使用项目内匹配 SQLite 原生模块的 Node 20：

```powershell
.\.runtime\node20\node.exe --test server/test server/features/private-chat/tests
npm --prefix client run build
```

在后台启动 Vite 开发服务（端口 5178）后运行：

```powershell
node client/src/features/private-chat/tests/privateReplyReroll.e2e.cjs
```

浏览器测试使用真实私聊组件与模拟 API，不调用收费模型，也不修改用户数据库。可通过 `REROLL_TEST_URL` 指定其他开发服务地址。
